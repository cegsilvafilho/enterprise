# PRD: Dignidade 360 Enterprise

## 1. Visão do produto

A Dignidade 360 Enterprise é uma plataforma digital para coordenação de cuidados paliativos, suporte familiar e gestão institucional.

O produto deve acompanhar o paciente ao longo do tempo, registrar sintomas e necessidades, organizar alertas, apoiar decisões compartilhadas, permitir comunicação segura e oferecer indicadores para gestão.

## 2. Objetivos estratégicos

1. Identificar precocemente pacientes com necessidade paliativa.
2. Monitorar sintomas, sofrimento, funcionalidade e sobrecarga familiar.
3. Organizar planos de cuidado e planos de crise.
4. Priorizar demandas por risco e SLA.
5. Apoiar profissionais com histórico longitudinal e registro estruturado.
6. Dar visibilidade operacional a gestores.
7. Reduzir fragmentação entre hospital, domicílio, ambulatório e rede.
8. Criar dados confiáveis para melhoria contínua.

## 3. Perfis

### Paciente

Usa a plataforma para:

- registrar sintomas;
- consultar plano de cuidado;
- consultar plano de crise;
- enviar mensagens;
- ver agenda;
- registrar preferências;
- autorizar cuidador.

### Cuidador/familiar

Usa para:

- registrar sintomas em nome do paciente;
- acompanhar tarefas;
- consultar plano de crise;
- pedir apoio;
- receber orientações;
- registrar sobrecarga.

### Profissional

Usa para:

- ver fila assistencial;
- atender alertas;
- consultar timeline;
- registrar condutas;
- revisar plano de cuidado;
- registrar reunião familiar;
- escalonar casos.

### Coordenador de cuidado

Usa para:

- distribuir alertas;
- monitorar SLA;
- acompanhar transições;
- coordenar equipe;
- garantir seguimento.

### Gestor

Usa para:

- ver indicadores agregados;
- monitorar unidades;
- acompanhar equipes;
- configurar linhas de cuidado;
- medir adesão, SLA e qualidade.

### Admin

Usa para:

- configurar organização;
- gerenciar usuários;
- gerenciar permissões;
- configurar protocolos;
- gerenciar integrações.

## 4. Proposta de valor

### Para pacientes

- Acompanhamento contínuo.
- Mais segurança em casa.
- Orientações claras.
- Menos abandono entre consultas.
- Plano de crise acessível.

### Para família

- Mais clareza sobre o que fazer.
- Registro de tarefas.
- Canal de apoio.
- Monitoramento de sobrecarga.
- Suporte no luto, quando aplicável.

### Para equipe

- Fila organizada.
- Priorização por risco.
- Histórico estruturado.
- Registro de decisões.
- Melhor continuidade do cuidado.

### Para instituição

- Serviço paliativo escalável.
- Indicadores de operação.
- Menos retrabalho.
- Melhor transição hospital-domicílio.
- Governança e qualidade.

## 5. Funcionalidades obrigatórias do MVP robusto

- Login por perfil.
- Cadastro de paciente.
- Cadastro de cuidador autorizado.
- Check-in de sintomas.
- Cálculo de prioridade.
- Alertas com status e SLA.
- Fila profissional.
- Plano de cuidado.
- Plano de crise.
- Chat ou mensagens.
- Registro de conduta.
- Dashboard gestor.
- Linhas de cuidado.
- Equipes.
- Consentimento.
- Auditoria básica.

## 6. Funcionalidades avançadas

- Timeline longitudinal completa.
- Escalas funcionais.
- Planejamento Antecipado de Cuidados.
- Diretivas e preferências.
- Reuniões familiares.
- Suporte social.
- Espiritualidade.
- Luto.
- Integração com prontuário.
- Integração com agenda.
- BI avançado.
- API para parceiros.

## 7. Princípios de experiência

- Linguagem simples.
- Interface acolhedora, mas profissional.
- Poucos cliques para ações críticas.
- Separação clara entre orientação e emergência.
- Acessível para idosos e cuidadores.
- Responsiva para celular.
- Gestor deve ver operação com densidade e clareza.
